# アート方針 1.0 — 顔写真MBTI診断（2026-11-14 確定）

現行実装から読み取った世界を正本化したもの。以後のUI作業は開始時に必ずこれを読む。

## 世界の言葉
- キーワード: **あたたかい／まるい／おもちゃっぽい**
- やらない雰囲気: 臨床的・検査っぽい冷たさ、サイバーな近未来、ゴシックや高級感。MBTIを「科学の診断」に見せない。

## 根拠マップ（コンセプト → 選択 → 理由）
| コンセプト要素 | アートの選択 | 理由 |
|---|---|---|
| エンタメであり診断ではない | クリーム地＋丸ゴシック2書体 | 「測ってあげる」ではなく「一緒に遊ぶ」温度にする |
| 撮るのが主行動 | 主CTAは常にコーラル（#FF6B4A系）＋立体影pill | どの画面でも「押すのはこれ」と色で学習できる |
| 計測のワクワク | ティールは「計測・スキャン」の意味だけに限定 | 色に意味を持たせ、主CTAと競わせない |
| 狙う（ミッション） | 黄色はミッションと達成報酬だけに限定 | 日替わりお題が日常の中で特別に見える |
| 見せたくなる（結果） | 結果ヘッダーはそのタイプの色1色で大きく | タイプの色＝その人の「今日の旗」。ただし16色は明度・彩度を揃える |

## 色の性格
- 基調: 温かいクリーム（明 #FFF8EE 系／暗は温かい茶黒）。白カード＋単一の柔らかい影。
- 役割色: 主CTA=コーラル、計測=ティール、ミッション/達成=黄、タイプ色=16色（明度・彩度を統一レンジに揃え、白文字が読めない色は濃い文字に切替）。
- 色の値はトークン（CSS変数）1か所だけが正本。JS/Canvasも変数から取得し、直書きhexを持たない。

## 形の言語
- 角丸は役割3段: 大カード 28px／内側の箱 16px／チップ・ボタン 999px。それ以外は作らない。
- ボタンは pill＋下方向の立体影（0 6px 0）が主言語。例外はシャッターボタン（丸・撮影の意味）だけ。
- アイコン/イラスト: 線は太め・丸端。顔イラストは黒線＋肌色＋ほっぺの最小構成。

## 文字と密度
- 書体: 見出し=Zen Maru Gothic 900、本文=M PLUS Rounded 1c。
- サイズは 12（注記）／13.5（補助）／15.5（本文）の3段＋見出し系（21/24/clamp）。0.5px刻みの近接段は作らない。
- 1画面1メッセージ。ホームの主役は「撮る/選ぶ」、結果の主役は「タイプ」。補助は2〜3個まで、それ以外は畳む。

## 動きの性格
- 意味のある動きだけ: スキャン=計測中、pop=結果の登場、紙吹雪=ミッション達成のみ。
- 全アニメーションに prefers-reduced-motion 対応を必須とする。

## 良い例／悪い例
- 良い: 主ボタンがどの画面でもコーラルpill。結果の詳細は畳まれ、タイプとシェアが先に見える。
- 悪い: 画面ごとに主ボタンの色が変わる。黄色やティールを装飾で散らす。新しい角丸・文字サイズを場当たりで足す。
