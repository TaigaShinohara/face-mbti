# アート方針 2.0 — 顔写真MBTI診断（2026-11-16 改定）

本人の指示（2026-11-16）で、添付のローポリペンギン（Deepleのアイコン）を基準にアプリ全体の世界を組み替えた。以後のUI作業は開始時に必ずこれを読む。方針1.0（まるい／おもちゃっぽい）は廃止。

## 世界の言葉
- キーワード: **ローポリ／幾何学／あたたかい紙の世界**
- 基準画像: ローポリペンギン（多角形の面で組んだ幾何学ベクター、クリーム色の紙の上にネイビー・ティール・コーラル・オレンジ）。
- やらない雰囲気: 臨床的・検査っぽい冷たさ、サイバーな近未来、丸くて幼いおもちゃ感（1.0の世界）、グラデーションの多用（面はフラットな単色で組む）。

## 根拠マップ（コンセプト → 選択 → 理由）
| コンセプト要素 | アートの選択 | 理由 |
|---|---|---|
| エンタメであり診断ではない | クリームの紙地＋フラットな多角形の面 | ポスターのような「飾れる一枚」の温度にする |
| 撮るのが主行動 | 主CTAは常にコーラルレッド＋ネイビーのオフセット影 | どの画面でも「押すのはこれ」と色と形で学習できる |
| 計測のワクワク | ティールは「計測・スキャン」の意味だけに限定 | 色に意味を持たせ、主CTAと競わせない |
| 狙う（ミッション） | オレンジ〜黄はミッションと達成報酬だけに限定 | いつでも引き直せるお題が「もう1回」を誘う |
| 見せたくなる（結果） | 結果ヘッダーはそのタイプの色1色で大きく＋タイプフェイス画像 | タイプの色と顔がその人の「旗」になる |

## 色の性格（基準画像から採取したパレットが正本）
- 紙地: クリーム `#F3EAD8` 系（明）。暗は深いネイビー `#1B2436` 系に同じ差し色。
- 差し色: ネイビー `#22304A`／ティール `#1F7A8C`／コーラルレッド `#E4572E`／オレンジ `#F2A03D`／クリーム白 `#FBF6EA`。
- 役割色: 主CTA=コーラルレッド、計測=ティール、ミッション/達成=オレンジ、構造と文字=ネイビー。
- タイプ色=16色は、このパレットの色相の範囲に寄せた「面の色」として再調整する（彩度は中程度、明度を揃え、白文字が読めない色は濃い文字に切替）。
- 色の値はトークン（CSS変数）1か所だけが正本。JS/Canvasも変数から取得し、直書きhexを持たない。

## 形の言語
- 面はフラットな単色の多角形。装飾は三角形・ファセット（面の分割）・斜めの切り欠きで作り、丸いブロブやグラデーションの泡は使わない。
- 角丸は控えめに: 大カード 20px／内側の箱 12px／ボタンは「角を落とした多角形」寄りの 14px。チップだけ pill を許す。ボタン影はぼかさず、ネイビーのオフセット影（ずらし影）で面の重なりを表す。
- イラスト: タイプフェイス（ローポリ動物の生成画像）が基準。ヒーローやサンプル等の新規イラストも同じ画風（ローポリ・正面・紙地）に揃える。
- 写真の舞台（プレビュー/スキャン）も、破線の丸枠ではなく多角形の隅マーカー＋ファセット装飾で世界に合わせる。

## 文字と密度
- 書体: 見出し=Zen Kaku Gothic New 900（角の立つ幾何学感）、本文=M PLUS 1p。
- サイズは 12（注記）／13.5（補助）／15.5（本文）の3段＋見出し系トークン。0.5px刻みの近接段は作らない。
- 1画面1メッセージ。ホームの主役は「撮る/選ぶ」、結果の主役は「タイプ」。補助は2〜3個まで、それ以外は畳む。

## 動きの性格
- 意味のある動きだけ: スキャン=計測中、pop=結果の登場、紙吹雪=ミッション達成のみ。
- 全アニメーションに prefers-reduced-motion 対応を必須とする。

## 良い例／悪い例
- 良い: 主ボタンがどの画面でもコーラルレッド＋ネイビーのずらし影。背景に小さな三角ファセットが静かに散る。タイプフェイス画像と画面の色が同じ世界に見える。
- 悪い: 画面ごとに主ボタンの色が変わる。丸いおもちゃ風の装飾が残る。グラデーションで「それっぽく」する。新しい角丸・文字サイズを場当たりで足す。
