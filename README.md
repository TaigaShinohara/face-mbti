# 顔写真MBTI診断（Face MBTI）

顔写真からMBTIの16タイプを“計測”する、ブラウザだけで動く**エンタメ専用**の静的Webアプリです。

`index.html` をブラウザで開くだけで使えます。ビルドもサーバーも不要です。

> ⚠️ これはエンタメアプリです。顔写真から性格タイプを科学的に判定できるものではありません。結果は写真の写り方（明るさや色味など）から決まる占い的な演出としてお楽しみください。

## 使い方

1. `index.html` を開く
2. 写真を選ぶ（ファイル選択／ドラッグ&ドロップ／貼り付け）、または「カメラで撮る」でその場で撮影する（写真がない場合はサンプル顔イラストでも試せます）
3. スキャン演出のあと、MBTIタイプ・解説・4軸バー・強み／注意点・恋愛／仕事スタイル・相性タイプが表示されます
4. 結果はテキストコピー、または縦長（1080×1920）のシェア画像カードとしてPNG保存できます

## 遊びが続く仕掛け

- **表情ミッション**：ランダムに出る「表情のお題＋目標タイプ」を提示。カード内のボタンで何回でも引き直しできます。診断結果が目標と一致すると達成演出、外れても一致した文字数と軸別の「あと少し」アドバイスが出ます
- **16タイプ図鑑**：全タイプをタップで閲覧できます

## 判定のしくみ

AIや顔認識モデルではなく、端末内での画像の実測です。

- 写真から **明るさ・鮮やかさ・コントラスト・左右バランス・ディテール量** を数値化します
- その値を E/I・S/N・T/F・J/P の4軸に割り当て、16タイプのうち1つを表示します
- カメラ撮影時も、選んだ写真と同じフローで解析します

## プライバシー

- 写真・映像は **端末（ブラウザ）内だけで処理** され、外部送信・保存はしません（通信コード自体が含まれていません）
- 通信が発生するのは Google Fonts の読み込みのみです（読み込めない環境では代替フォントで表示されます）
- カメラのストリームは、撮影後・診断開始時などに停止します
